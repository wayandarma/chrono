# CHRONO visual-direction prototypes (archived)

Throwaway prototypes from the design exploration. **Not part of the build.**
The question they answered: *what should CHRONO look like?*

Verdict: **Variant D "Cinema+"** — B's film-frame layout (letterbox bars,
full-bleed scene, low-left clock) + A's solid mechanical flip cards with
condensed Archivo digits + A's panel designs. Bodoni and tiny letter-spaced
labels were rejected as hard to read. C's split-flap alarm board was rejected
(changes the approved alarm UX, too many animated nodes).

These files should live on a throwaway git branch, not in main.
